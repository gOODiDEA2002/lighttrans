## 3. P1（T13 开始前必须修改）

### P1-1：连接测试缺少完整请求契约与成功判定

- [ ] **位置**：`docs/03-detailed-design.md` 第 545 至 549 行；`docs/06-ui-optimization-proposal.md` 第 119 至 125 行；T13。
- **问题**：当前只定义了方法签名、`max_tokens: 5`、10 秒超时和不写历史，但没有定义实际 HTTP 请求的关键内容。编码时仍需临时决定：
  1. 是否继续请求 `{baseURL}/chat/completions`；
  2. `stream` 使用 true 还是 false；
  3. `messages` 中发送什么最小内容；
  4. 耗时统计截至收到响应头、首个 token，还是完整响应解析结束；
  5. HTTP 2xx 但响应 JSON 不符合预期是否算成功；
  6. 取消按钮如何持有和取消测试 Task；
  7. 各错误是否完全复用 `TranslationError`，模型不存在或无权限如何呈现。
- **影响**：不同选择会改变费用、耗时数值、兼容范围和错误文案。项目规则禁止在详细设计未覆盖时由编码阶段即兴决定。
- **建议修改**：在详细设计第 13.2 节明确以下契约：
  - `POST {baseURL}/chat/completions`；
  - `stream: false`，`max_tokens: 5`，`messages: [{"role":"user","content":"Reply with OK."}]`；
  - 收到 2xx 且能解码 `choices[0].message.content` 后判成功，耗时统计到完成该解码；
  - 非 2xx 与网络错误复用现有 `TranslationError`；2xx 但结构异常按 `badResponse`；
  - SettingsView 持有独立测试 Task，重复点击或关闭窗口时取消；
  - 测试只使用当前表单内存值，不保存配置、不写历史；
  - 界面明确提示可能产生极少量 API 费用。

该问题只影响 T13。按照 T12 → 验收确认 → 提交 → T13 的顺序，在 T12 实施期间补充即可。

## 4. P2（建议在对应任务完成前修正）

### P2-1：`docs/06` 的垂直预算算术写错

- [ ] **位置**：`docs/06-ui-optimization-proposal.md` 第 41 行。
- **问题**：`100 + 8 + 28 + 8 + 190 + 8 + 190 + 8 + 20 + 28` 的结果是 **588 pt**，不是 596 pt。内部组件和间距合计 560 pt，加上下 padding 28 pt 后为 588 pt，窗口还剩 12 pt 余量。
- **建议修改**：把总高度改为 588 pt，并明确余下 12 pt 由两张结果卡动态平分或作为布局余量。详细设计已采用「平分剩余高度」，因此该笔误不阻塞 T12。

### P2-2：明确窗口尺寸指 contentRect 还是含标题栏的外框

- [ ] 面板为 full-size content view，设置与历史是标准标题栏窗口。建议在详细设计统一声明：560 × 600、520 × 450、680 × 480 分别指内容区尺寸还是完整窗口 frame，避免实现后比设计稿多出标题栏高度。推荐沿用现有历史窗口方式，按 `contentRect` 解释。

### P2-3：两张设置稿的图标与选中样式仍不完全一致

- [ ] 分类文字和顺序已经统一，但接口稿与模板稿使用的 SF Symbols、选中背景和描边风格仍有差异。实现时应以详细设计列出的 4 个 symbol 为准，所有页面复用同一个 Sidebar 组件。

### P2-4：补充浅色、深色与辅助功能验收

- [ ] T12–T14 当前主要验收布局和功能。UI 优化还应在对应任务验收时检查浅色、深色、Reduce Transparency、Increase Contrast、Reduce Motion，以及纯键盘操作和 VoiceOver 标签。T12 至少保留浅色、深色各一张真机截图再确认美观度。

### P2-5：清理或标注过期设计稿

- [ ] `docs/assets/` 中仍保留 `lighttrans_panel_streaming.jpg`、`lighttrans_panel_partial_fail.jpg` 和早期 mockup 等旧稿，其中部分与 v3.0 决策冲突。建议移动到明确的 `archive/` 目录或在 README 中列出当前有效稿，防止实施时引用错误图片。

### P2-6：任务提交与阶段确认应显式执行
