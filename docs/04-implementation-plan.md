# 实施计划（编码任务清单）

项目名：mac-translator（应用显示名：轻译 / LightTrans）
文档版本：v1.0（2026-07-13）
执行者：编码会话（Opus）
依据：03-detailed-design.md（详细设计）。本清单只安排「做什么、什么顺序、怎么验收」，实现细节一律以详细设计为准。任务共 14 项（T1 至 T14）。

## 0. 编码纪律（执行前必读）

1. 严格按详细设计实现；遇到文档未覆盖的决策点，停下向用户说明并补充设计，不得即兴决定。
2. 每完成一个任务立即按其"验收标准"验证通过后，再进入下一任务；不攒多个任务一次性验证。
3. 五条待验证假设（系统设计第 5 节 A-1 至 A-5）在对应任务中先验证再依赖；不成立时按文档给出的备选路径处理，并回写更新设计文档。
4. 注释用中文，代码与文档不使用表情符号。
5. 声称任务完成前，实际构建并运行确认；不得凭"代码写完了"即报告完成。

## 1. 任务清单

### T1 工程骨架

- 内容：创建 Package.swift（依赖 KeyboardShortcuts）、目录结构、空的入口文件，确保 `swift build` 通过。
- 同时验证假设 A-2：确认 KeyboardShortcuts 解析出的版本支持 macOS 14 部署目标；如冲突，按备选处理并更新系统设计文档。
- 验收标准：`swift build` 成功，无警告级以上的问题。

### T2 打包脚本与最小可运行应用

- 内容：Resources/Info.plist、Scripts/build-app.sh；AppDelegate 先只实现状态栏图标与右键菜单（设置项暂为空实现，退出可用）。
- 验收标准：运行脚本产出 LightTrans.app；双击启动后菜单栏出现图标、Dock 无图标（LSUIElement 生效）、右键菜单可退出。

### T3 配置层

- 内容：ConfigStore、KeychainHelper，按详细设计第 2 节实现全部配置项与默认值。
- 验收标准：临时在启动时写入并读回一个测试 Key，确认钥匙串存取正常（验证后删除临时代码）；UserDefaults 各项默认值正确。

### T4 翻译服务

- 内容：TranslationService、SSE 解析、TranslationError 与错误映射，按详细设计第 6、7 节实现。
- 验收标准：
  - 用无效 Key 调一次真实接口，确认走到 invalidKey 分支；
  - 用户提供真实 Key 后，命令行或临时调用验证流式输出逐段到达、[DONE] 正常收尾；
  - 中途取消后连接立即中断（可用日志确认）。
- 说明：本任务需要用户提供一个可用的接口地址与 API Key 做真实验证；拿到之前可先完成编码并用无效 Key 验证错误分支，真流式验证挂起待用户提供。

### T5 浮动面板窗体与快捷键

- 内容：FloatingPanel、togglePanel 定位与显隐逻辑、Option+T 全局快捷键监听。
- 首先验证假设 A-1：面板内放一个临时输入框，真机确认中文输入法（含候选窗）工作正常；不成立则按备选改为激活式面板，并更新设计文档后再继续。
- 验收标准：任意应用前台时按 Option+T 面板呼出且输入框获焦；再按一次隐藏；点击面板外自动隐藏；Esc 隐藏；全屏应用上可呼出。

### T6 面板界面与翻译交互

- 内容：TranslatePanelView、PanelViewModel，按详细设计第 4.2、4.3 节实现完整交互。
- 验收标准：输入文字 Cmd+Return 后译文逐字显示；翻译中可停止；复制按钮工作且有"已复制"反馈；错误场景（断网、无效 Key）显示对应中文文案；隐藏再呼出内容保留。

### T7 历史记录与历史窗口

- 内容：HistoryStore、HistoryWindowView、状态栏菜单"历史记录…"入口、PanelViewModel 翻译结束时写入记录，按详细设计第 10 节实现。
- 首先验证假设 A-4：向 iCloud 云盘目录写入测试文件，确认可直接读写（记录是否出现授权弹窗），并在访达"iCloud 云盘"中确认文件出现；随后验证假设 A-5：对 `.icloud` 占位文件调用下载接口观察行为。任一不成立按系统设计给出的备选处理并回写文档。
- 验收标准：完成、手动停止、失败三种结束状态各产生一条正确记录；记录写入 iCloud 云盘的 `LightTrans/history/history-{设备标识}.jsonl`；历史窗口按时间倒序合并显示、关键字过滤与复制可用；关闭历史开关后不再产生新记录；模拟 iCloud 不可用（临时改判定逻辑或在未登录环境）时自动退化为本机目录。

### T8 设置窗口

- 内容：SettingsView 及 AppDelegate.openSettings，按详细设计第 5 节实现（含历史记录开关与存储位置显示）。
- 验收标准：右键菜单打开设置且窗口获焦可输入（L-2 验证）；各配置项修改后立即生效于下一次翻译；API Key 保存后重启应用仍可用；快捷键重新录制后立即生效。

### T9 开机自启

- 内容：SMAppService 注册/注销，绑定设置开关。
- 验证假设 A-3：将 .app 拷贝至 /Applications 后开启自启，注销重登确认自动启动；失败则按备选（引导手动添加登录项）处理并更新设计文档。
- 验收标准：开关状态与系统"登录项"设置一致；重登验证通过（或已按备选落地）。

### T10 总验收与文档收尾

- 内容：对照需求文档 FR-1 至 FR-11 逐条人工验证，记录结果于本文档第 2 节；更新 README.md（构建、安装、配置说明）。
- 验收标准：FR-1 至 FR-11 全部通过（FR-11 的跨设备部分若暂无第二台电脑，先验证本机写入 iCloud 云盘成功并标注待验）；README 按实际情况更新完毕。

### T11 应用图标与一键安装更新

- 内容：按详细设计第 12 节生成应用图标与 `.icns` 资源；更新 `Info.plist` 和打包脚本；新增一键安装或更新脚本。
- 验收标准：
  - `Resources/AppIcon.png` 为 1024 x 1024 的标准 PNG，包含透明圆角，`Resources/AppIcon.icns` 可被 `iconutil` 识别；
  - 运行 `bash Scripts/build-app.sh` 后，应用包包含图标资源，`Info.plist` 图标配置正确，严格签名校验通过；
  - 首次运行 `bash Scripts/install-app.sh` 可安装并启动应用；再次运行可替换已安装版本并重新启动，配置、钥匙串和历史数据不受影响；
  - 安装过程中若应用正在运行，只退出目标安装路径对应的进程；替换失败时旧版本可恢复。
- 验收结果（2026-07-15）：通过。图标尺寸、透明圆角与全部 ICNS 图层已检查；强制使用 `/Library/Developer/CommandLineTools` 并删除 `.build` 后，重新解析、补丁处理并编译 `KeyboardShortcuts 2.4.0`，release 构建、应用包资源和严格签名校验通过；安装与运行中更新均已执行，更新前后进程号发生变化，安装目录内无临时文件或旧版本备份残留。

### T12 UI-1 浮动翻译面板重构

- 内容：按详细设计第 13.1 节与 UI 方案 v3.0 重构 `FloatingPanel.swift`、`TranslatePanelView.swift`、`PanelViewModel.swift`、`AppDelegate.swift`。
  - 窗体启用 NSVisualEffectView（.popover）材质与 14pt 圆角；
  - 输入区卡片化，增加一键清空（xmark）、字符统计（82 字符）；
  - 维持 Esc 严格隐藏逻辑；
  - 操作栏生成中切换为「停止」按钮；
  - 双路卡片独立展示状态（正在直译/正在转写/完成/失败文案），平分剩余空间；
  - 复制按钮带 1.5 秒绿色 checkmark「已复制」反馈；
  - 底部工具栏通过闭包依赖注入直达设置与历史窗口。
- 验收标准：
  - 在 560 × 600 真实窗口下，所有控件垂直排版与设计预算表吻合，无截断或溢出；
  - 翻译中点击「停止」按钮能立即中断网络请求；
  - 按 Esc 稳定隐藏面板；点击清空仅清除输入；
  - 点击底部齿轮与时钟图标能唤起并获焦设置/历史窗口。
- 验收结果（2026-08-21）：通过。NSVisualEffectView 原生毛玻璃材质与 14pt 圆角生效；输入框 100pt 并与清空/字符数避让无遮挡；生成中主按钮切换为停止；双路独立完成态展示「已完成」；Release 打包及真机交互验证通过。

### T13 UI-2 设置窗口分页与连通测试

- 内容：按详细设计第 13.2 节重构 `SettingsView.swift`，并在 `TranslationService.swift` 中新增 `testConnection` 探测接口。
  - 改造为固定 4 项侧边栏分类导航（接口配置、提示词模板、通用与快捷键、历史记录），窗口固定 520 × 450 pt；
  - 接口配置：模型名保持自由输入，API Key 提供明暗文切换；
  - 连通性测试：发起 max_tokens: 5 探测请求（超时 10s，支持取消，不写历史），提供毫秒耗时与状态反馈；
  - 提示词模板：同页展示直译与转写双模板，带 {{text}} 占位符校验徽章。
- 验收标准：
  - 侧边栏分类切换平滑，右侧各页面独立展示无裁切；
  - 输入有效/无效配置点击「测试连接」能准确反馈耗时或错误，且确认不向 HistoryStore 写入记录；
  - 直译与转写双模板均能正常编辑并持久化。
- 验收结果（2026-08-21）：通过。520 × 450 窗口侧边栏 4 项真实分页无裁切；API Key 眼睛图标明暗文切换正常；连通性测试精准反馈耗时/错误且绝不写历史记录；双模板同页展示与占位符徽章正常生效。

### T14 UI-3 历史窗口密度与详情重构

- 内容：按详细设计第 13.3 节重构 `HistoryWindowView.swift`。
  - 列表项摘要最多 2 行，增加语义状态点（绿/橙/红）与无障碍标签，设备名降为次要文本；
  - 搜索栏显示匹配计数，搜索/刷新自动联动选中项（不存在则选首项，无结果置空）；
  - 详情区元数据 2 行网格排版（长文本尾部截断+tooltip），正文分 3 卡片独立排版与复制。
- 验收标准：
  - 680 × 480 尺寸下左右分栏比例协调，长设备名/模型名不溢出；
  - 搜索过滤与空状态展示自然，无旧详情残留；
  - 详情各卡片独立复制与状态展示准确。
- 验收结果（2026-08-21）：通过。680 × 480 尺寸下左侧 2 行摘要与微型语义色点展示清晰，移除蓝色徽章降噪效果明显；搜索实时计数并闭环联动选中/首选/空状态；元数据 2 行网格与 3 张独立正文卡片（带 1.5 秒绿色 checkmark）运行良好。
