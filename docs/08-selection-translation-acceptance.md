## 3. 系统与业务路径证据

### 3.1 冷启动与双路翻译

Safari 真实右键菜单路径为「Services > 轻译：打开面板」。触发前安装版轻译未运行；触发后系统启动 `/Applications/LightTrans.app`。包含首尾空格、多行、中文、英文、Emoji 和组合字符的合成选区满足以下结果：

- 历史中的 `input` 与来源选区逐字符一致；
- `status = done`；
- `literalOutput` 与 `rewriteOutput` 均非空；
- `error` 为空；
- 通用剪贴板 `changeCount` 在触发前后均为 `7073`。

Chrome 真实右键菜单也包含「Services > 轻译：打开面板」。触发后两路实际请求均返回 HTTP 200，历史记录满足同一组输入、结果和状态检查。

### 3.2 真实流式任务替换

通过安装版服务连续发送两条合成选区，间隔 `150 ms`：

| 记录 | 数量 | 状态 |
| --- | ---: | --- |
| 第一条旧任务 | 1 | `stopped` |
| 第二条最新任务 | 1 | `done` |

两次 `NSPerformService` 均返回成功；全过程通用剪贴板 `changeCount` 不变。该结果验证系统设计 A-11：新请求等待旧协调任务结束并写入历史后，才执行最新请求。

### 3.3 长文本保护

安装版服务连续接收两条 `5,001` 字符的合成选区，两次系统调用均成功。两次请求后面板都保持可见，frame 均为 `560 x 600 pt`，位置完全一致，通用剪贴板 `changeCount` 不变。历史文件核对结果为对应长文本记录数 `0`。单元测试进一步确认该分支只载入原文、显示费用保护提示、不调用模型、不写历史；用户已目视确认费用保护提示正确显示。
