# 需求文档

项目名：LightTrans（应用显示名：轻译）
文档版本：v1.3（2026-08-27）
状态：已实现（FR-1 至 FR-12；FR-13 至 FR-15 未实施）

## 1. 背景与目标

开发者需要一个 macOS 上的翻译小工具：输入一段文字，工具将其套入预设的提示词模板，交给大模型处理，并展示模型输出的译文。

核心目标按优先级排序：

1. 易用：常驻菜单栏，全局快捷键随时呼出，用完即走。
2. 可配置：接口地址、密钥、模型名、提示词模板均可在设置中修改，兼容符合本项目 Chat Completions 请求与响应格式的模型服务。
3. 轻量：独立 App，无额外运行环境依赖，冷启动快，内存占用低。

## 2. 用户与使用范围

- 项目公开源码，面向能够自行配置模型接口的 macOS 用户。
- GitHub Release 提供 Apple Silicon（`arm64`）未签名预览版，产物采用 ad-hoc 签名，不使用 Developer ID 签名与 Apple 公证；Intel Mac 需要从源码构建。
- 预览版必须标明签名状态、处理器架构、SHA-256 校验方式和 macOS 首次放行步骤，不得表述为已通过 Apple 安全审核。

## 3. 基础功能需求（已实现）

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-1 | 菜单栏常驻 | 启动后仅在菜单栏显示图标，不出现在 Dock 与 Cmd+Tab 切换器中。左键点击图标呼出翻译面板；右键弹出菜单（设置、退出）。 |
| FR-2 | 全局快捷键呼出 | 默认 Option+T，可在设置中重新录制。按下时若面板未显示则显示并聚焦输入框；已显示则隐藏。面板内按 Esc 隐藏。 |
| FR-3 | 翻译面板 | 浮动面板（类似聚焦搜索 Spotlight 的样式，出现在屏幕中上方）。包含：多行输入区、翻译按钮（快捷键 Cmd+Return）、结果显示区、复制按钮、状态与错误提示区。 |
| FR-4 | 翻译执行 | 将输入文字替换提示词模板中的 `{{text}}` 占位符，调用 OpenAI 兼容的 chat/completions 接口，流式接收并逐字追加显示译文。翻译进行中按钮变为"停止"，可中断本次请求。 |
| FR-5 | 结果复制 | 结果区旁提供复制按钮，一键将完整译文写入剪贴板，并给出短暂的"已复制"反馈。 |
| FR-6 | 设置窗口 | 可配置项：接口地址（Base URL）、API Key、模型名、提示词模板、最大输出 token 数、全局快捷键、开机自启开关。 |
| FR-7 | 密钥安全存储 | API Key 存入 macOS 钥匙串（系统内置的密码保险柜），不写入任何明文文件；其余配置存入系统偏好存储（UserDefaults）。 |
| FR-8 | 错误提示 | 常见失败场景在面板内用平实中文提示原因：密钥无效、请求过于频繁、余额不足、网络不可用、接口地址错误、返回格式异常。 |
| FR-9 | 自动隐藏 | 面板失去焦点（点击面板外部区域）时自动隐藏。隐藏不清空内容，再次呼出时保留上次的输入与结果。 |
| FR-10 | 历史记录 | 每次发起翻译，结束时（完成、手动停止或失败）将原始输入、译文输出、时间、设备名、模型名、结束状态追加保存为一条历史记录。记录采用只追加、不修改的方式写入本机专属的历史文件。设置中提供记录开关（默认开启）。 |
| FR-11 | 多设备同步与合并显示 | 历史文件存放于 iCloud 云盘（iCloud Drive）内本应用的专用文件夹，由系统在多台电脑间自动同步。每台电脑只写入自己的历史文件，杜绝同步冲突。历史窗口读入文件夹内全部设备的历史文件，按时间倒序合并显示，支持关键字过滤、查看完整原文与译文、复制。未启用 iCloud 云盘的电脑自动退化为仅存本机。 |

## 4. 增量需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-12（已实现） | 选中文字翻译 | 在支持 macOS 服务的应用中选中文字后，调用 `轻译：打开面板`。轻译把原文填入输入框并自动执行直译和转写；选区超过 `5,000` 个 Swift `Character` 时只填入、不自动请求。第一阶段不申请「辅助功能」权限，不读取或修改通用剪贴板。产品设计见 `07-selection-translation-feature-design.md`，实现细节见 `03-detailed-design.md` 第 14 节。 |
| FR-13 | 多套提示词模板 | 支持保存多套模板（翻成中文、翻成英文、润色等），面板上快速切换。 |
| FR-14 | 单路翻译并复制 | 第一阶段独立验收通过且确认存在高频需求后，增加 `轻译：直译并复制` 与 `轻译：转写并复制`；翻译期间若剪贴板发生变化，不覆盖较新的内容。 |
| FR-15 | 受控原位替换 | 先验证 macOS 返回型服务在目标可编辑控件中的兼容性、超时和选区一致性。全部门槛通过后再决定是否实施；终端永久禁止自动粘贴和替换。 |

## 5. 非功能需求

| 编号 | 需求 | 指标 |
| --- | --- | --- |
| NFR-1 | 启动性能 | 冷启动至菜单栏图标可用不超过 1 秒；快捷键呼出面板无可感知延迟。 |
| NFR-2 | 资源占用 | 空闲时内存占用控制在 100 MB 以内。 |
| NFR-3 | 系统兼容 | 最低部署目标 macOS 14；实际运行环境为本机 macOS 15.7.4。 |
| NFR-4 | 隐私 | 除调用用户自行配置的大模型接口外，不向任何第三方发送数据；不采集使用数据。历史记录包含完整原文和结果，以未额外加密的 JSON Lines 文件存储；检测到 iCloud 云盘时由系统同步。 |
| NFR-5 | 费用保护 | 通过最大输出 Token 数限制每一路请求的结果上限；通过 `5,000` 字符自动翻译上限，阻止误选长文后立即发起双路请求。限制只控制自动执行，不截断原文。 |
| NFR-6 | 历史数据可靠性 | 历史文件只追加、不修改；一个文件只有一台设备写入。多设备同步依赖 iCloud 云盘（前提：各电脑登录同一 Apple ID 且启用 iCloud 云盘），同步时效由系统决定（通常数秒至数分钟），本工具不承诺实时到达。无付费开发者账号，不使用 CloudKit 等需要授权的 iCloud 能力。 |
| NFR-7 | 系统集成边界 | 第一阶段只使用 macOS 服务接收纯文本，不模拟复制、粘贴或键盘输入。来源应用不支持服务时，保留手动复制、呼出面板和粘贴的现有流程。 |

## 6. 明确不做的事

- 账号体系、云端同步、多语言界面、自动更新。
- 应用内置任何厂商的默认密钥。
- Windows / Linux / iOS 版本。
- 向所有应用注入自定义顶层右键菜单。
- 在终端中自动粘贴、替换或执行生成结果。

## 7. 验收口径

第一期完成的标准：在本机上，从构建产物双击启动应用后，FR-1 至 FR-11 全部按"说明"列描述的行为逐条人工验证通过（FR-11 的跨设备合并需在第二台电脑上验证，若暂不具备条件，可先验证"记录正确写入 iCloud 云盘文件夹"并将跨设备部分标注待验）；验证记录写入实施计划文档的验收清单。

FR-12 完成的标准：对照 `07-selection-translation-feature-design.md` 第 14 节和实施计划 T17，验证服务注册、冷启动、双路翻译、长文本保护、连续触发、历史记录、剪贴板不变、权限边界和目标应用兼容性。FR-14、FR-15 不计入 T17 验收。
