# LightTrans v5 视觉基准

> 状态：已确认（2026-08-21）
>
> 适用环境：macOS 15.7.4、深色外观、2× backing scale
>
> 目标：把 `docs/assets/` 的视觉方向转换为无冲突、可实现、可截图比较的唯一基准

> 公开发布清理：历史窗口基准图于 2026-08-27 使用相同状态重新采集，仅将个人设备名替换为中性样例，不改变尺寸与视觉规则。

## 1. 基准原则

1. 窗口标注尺寸均指完整 `window.frame`，包含标准标题栏。
2. 浮动面板固定为 560 × 600 pt；设置窗口固定为 520 × 450 pt；历史窗口初始 frame 为 680 × 480 pt。
3. 几何尺寸以 pt 为单位；在 2× 屏幕上对应 2 个物理像素。
4. 深色外观是首轮截图比较基准。浅色外观继续使用系统语义色，但不与旧深色 JPG 做像素比较。
5. 系统字体、SF Symbols、毛玻璃采样和抗锯齿由 macOS 决定。验收以几何、颜色层级和视觉位置为主，不要求与 AI 生成 JPG 的字体笔画逐像素相同。
6. 旧设计图只提供方向。v5 基准确认后，发生冲突时以本文件和 v5 基准图为准。

## 3. 浮动翻译面板

### 3.1 完整尺寸

- `window.frame`：560 × 600 pt。
- 无可见标准标题栏，内容覆盖完整 frame。
- 外边距：14 pt。
- 内部可用宽度：532 pt；内部可用高度：572 pt。

### 3.2 默认高度分配

| 区域 | 高度 |
| --- | ---: |
| 输入卡片 | 100 pt，可调范围 70–240 pt |
| 高度手柄命中区 | 10 pt，胶囊 36 × 4 pt |
| 操作栏 | 28 pt |
| 直译结果卡片 | `(484 - inputHeight) / 2` |
| 转写结果卡片 | `(484 - inputHeight) / 2` |
| 底部辅助栏 | 20 pt |
| 5 个区域间距 | 6 pt × 5 |

### 3.3 视觉与状态

- 输入卡片不显示英文「Input」标题；保留右上清空按钮和右下「N 字符」。
- 输入正文使用 14 pt 系统字体，不使用等宽字体。
- 操作栏使用完整圆角容器。空闲时仅显示右侧蓝色「翻译 ⌘↩」；生成时左侧显示 ProgressView 和「正在生成…」，右侧显示红色「停止」。
- 每个结果卡片由 28 pt 标题栏、分隔线和可滚动正文组成。
- 面板结果复制按钮采用 22 × 22 pt 纯图标按钮；成功后原位切换绿色 `checkmark` 1.5 秒。
- 局部失败只在标题栏显示红色「失败：原因」，不显示单路「重试」。重新执行仍使用全局 `⌘↩`。
- 高度手柄属于正式基准，不允许因为旧图没有手柄而删除。

## 4. 设置窗口

### 4.1 完整尺寸与分栏

- `window.frame`：520 × 450 pt，包含 28 pt 标准标题栏。
- 内容区高度：由 AppKit 按标题栏实际高度反算，目标约 422 pt。
- 左侧导航区：140 pt，包含右侧 1 pt 分隔线。
- 右侧内容区：380 pt。
- 右侧内容内边距：左、右各 16 pt；上、下各 16 pt。
- 所有页面复用同一套导航图标、字号和实心蓝色选中样式。

### 4.2 接口配置页

- 页面标题：17 pt semibold。
- 表单标签：13 pt regular；控件高度 26 pt；字段组间距 10 pt。
- API Key 眼睛按钮位于同一个圆角边框容器内。
- 测试空闲态：显示「连通性测试」标签与「测试连接」按钮。
- 测试成功态：绿色「当前配置连接成功（185 ms）」与按钮同行。
- 测试中态：按钮替换为「取消测试」。
- 长错误态：按钮保持第一行，错误文本在下一行显示，最多 2 行。
- 极少量费用提示置于操作区下方，使用 11 pt 次要文本。

### 4.3 提示词模板页

- 两张模板卡片完整显示，不使用页面滚动。
- 标题栏高度：34 pt；图标 13 pt；标题 13 pt semibold；校验徽章 11 pt。
- 卡片之间间距：12 pt。
- 编辑区使用 13 pt 系统字体；内容内边距 10 pt。
- 有效模板显示绿色徽章「占位符 {{text}} 已就绪」；无效模板显示橙色徽章「缺少 {{text}}」。

## 5. 历史窗口

### 5.1 完整尺寸与分栏

- 初始 `window.frame`：680 × 480 pt，包含 28 pt 标准标题栏。
- 左侧区域：270 pt，包含右侧 1 pt 分隔线。
- 右侧区域：410 pt。

### 5.2 左侧搜索与列表

- 搜索头部采用两行结构：第一行是完整搜索框；第二行左侧显示「找到 N 条记录」，右侧显示刷新按钮。
- 搜索框非空时，在输入框尾部显示清空按钮。
- 搜索头部总高度：76 pt。
- 列表行高度：64 pt。
- 第一行：6 pt 状态点、原文摘要、时间。
- 第二行：首选译文摘要、设备名。
- 选中行使用白色 10% 背景和 6 pt 圆角。

### 5.3 右侧详情

- 内容内边距：16 pt；卡片间距：12 pt。
- 元数据卡片固定为两行：时间与状态、设备与模型。
- 原文、直译、转写使用三张独立完整卡片。
- 历史详情空间充足，复制按钮使用带「复制」文字的紧凑按钮；复制后显示绿色「已复制」1.5 秒。
- 无记录、无匹配、未选择三种空状态保持区分。

## 6. 与旧设计的明确差异

1. 不采用 `lighttrans_panel_partial_fail.jpg` 中的局部「重试」。
2. 不采用 `lighttrans_panel_streaming.jpg` 中的英文「Input」和等宽输入字体。
3. 新增高度手柄，旧面板图在该点失效。
4. 设置成功状态采用同行布局；长错误允许换到下一行。
5. 历史搜索恢复两行结构，同时保留刷新入口。
6. 面板使用纯图标复制；历史详情使用带文字复制。按钮形式按空间密度区分，不强制跨窗口完全相同。

## 7. 截图验收

### 7.1 必测状态

- 面板：idle、streaming、done、partial-fail、stopped；输入高度 70、100、240 pt。
- 设置：API idle、testing、success、long-error；模板 valid、invalid。
- 历史：正常选择、搜索命中、无匹配、无记录、长设备名和长模型名。
- 菜单栏：深色、浅色、按下高亮。

### 7.2 误差范围

- 窗口 frame：0 pt 误差。
- 分栏、卡片外框、控件位置和尺寸：允许 ±1 pt。
- 字号和字重：不允许偏差。
- 固定颜色：每个 RGB 通道允许 ±3。
- 毛玻璃背景、SF Symbols 和字体抗锯齿不纳入逐像素硬阈值，但必须通过 50% 透明叠加检查位置和视觉权重。
- 不接受仅凭 `swift build` 或肉眼描述判定视觉通过；每个必测状态必须保留真实截图。

## 8. 实施门槛

本基准经确认后：

1. 将 `docs/assets/README.md` 改为以 v5 为唯一实施基准。
2. 旧图移入 `docs/assets/archive/`，不再与当前基准并列。
3. Cursor 按本文件实施，不自行修改 token。
4. Codex 使用真实截图、frame 数据、构建和签名结果验收。
